# O1a inert operations records and bounded decoding

Authority: accepted October 7 operations scope in [intent.md](intent.md), implementing the first source stage of [operations control plane](operations-control-plane.md). Canonical status: [development.md](development.md). Owner: Jeff; root owns semantics, privacy, integration and publication. O1a builds the complete closed vocabulary and bounded decoder before O1b's deterministic graph/timeline reducer. It does not complete O1, live operations, authority adapters or V1.

## Outcome and boundary

Provide a portable `rangoon-ops` crate which decodes caller-supplied minimized observations into an immutable bounded window, canonical bytes and an inventory. No I/O, clock, randomness, policy evaluation, authentication, grant/token issuing, secret custody, telemetry collection, database, provider/engine connection or execution. Neither a well-formed record nor a digest proves producer identity, delegation eligibility, enforcement, consent, completeness or authenticity. All output has authority `none`, authenticity `unverified` and execution `unavailable`, regardless of reported coverage or state. The crate cannot manufacture application-minted identities: it checks their syntax; a future trusted ingress must mint/authenticate them.

O0's requirements remain intact. O1b must implement effective-evaluation lineage, decisions/attempts, explicit gaps/conflicts, snapshot fences, replay, coverage and graph projections before O1 is complete. O1a is a deliberate type/decoder stage, not a substitute policy or projection engine. It preserves relationship inputs without declaring them valid. O2 views and O3 ingestion cannot treat O1a inventory as an approval or permission check.

## Closed schema and API

`decode_window(input: &[u8]) -> Result<DecodedWindow, DecodeError>` accepts only UTF-8 JSON schema `rangoon.ops.window.v1`. `DecodedWindow` is not deserializable or publicly constructible; private owned fields expose read-only `canonical_bytes()`, `canonical_digest()` and `inventory()`. The decoder preserves array/string order and values; typed serialization normalizes object field order, never trims, drops or replaces user values. Digest is SHA-256 of canonical bytes, internal consistency only. No field or method named `authorize`, `approve`, `is_allowed` or executable grant exists.

Every object and tagged record is closed, every field is required, and nullable fields must be explicitly present as `null` or their value. Reject same-value duplicate object keys, unknown/missing fields, extra fields on enum variants, unknown schema/kinds, invalid UTF-8, noninteger/out-of-range numbers and trailing content. Errors are fixed codes only: `input_limit`, `invalid_encoding`, `invalid_json`, `duplicate_field`, `depth_limit`, `value_limit`, `collection_limit`, `unsupported_schema`, `invalid_record`, `canonical_limit`, or `serialization_failed`. Never return parser prose, input keys/values, URLs, paths or payload excerpts.

Top-level fields: `schemaVersion`, `snapshot`, `tail`. Snapshot fields: `snapshotId`, `reducerVersion` (exact `rangoon.ops.reducer.v1`), `scope`, `topology`, `prefixes`, `asOfMs`. Scope fields: `workspaceId`, `systemIds`, `environmentIds`, `engineIds`. Topology fields: `revisionId`, `nodes`, `edges`, `policyRevisionIds`, `coverageRevisionIds`. Node fields: `id`, `kind` (`actor`, `workflow`, `tool`, `resource`, `gateway`, `engine`, `approval_stage`), `recordId`. Edge fields: `id`, `kind` (`declared_dependency`, `request_flow`, `delegation_observation`, `mediation_observation`, `evidence_lineage`), `from`, `to`. These are declared/observed topology, never verified mediation.

Each prefix has `producerId`, `fenceId`, `watermark` (nullable Cursor), `events`. Cursor fields: `sequence`, `eventId`. Each event has `eventId`, `producerId`, `fenceId`, `sequence`, `previousEventId` (nullable), `observedMs` (nullable), `receivedMs` (nullable), `correlation` (nullable EventCorrelation), `record`. EventCorrelation fields are `workspaceId`, `systemId`, `environmentId`, `engineId`, `traceId`, `spanId`, and explicitly nullable `requestId`, `evaluationId`, `attemptId`, `policyRevisionId`. A null correlation is accepted only for inventory record kinds `actor`, `resource`, `tool`, `workflow`, or `engine`; all other event kinds require the correlation object. O1a checks presence and field syntax only; O1b checks whether envelope selectors agree with record context and related observations. Context-free inventory does not establish a correlated action trace. Prefixes retain complete bounded history, not a trusted projected-state cache. Tail events have the same shape. O1b will verify cursor/predecessor relationships and conflicting streams; O1a cannot establish that a supplied prefix is authentic or complete.

All application identity/reference fields, including trace/span and snapshot/fence IDs, use exact `ops:` plus 64 lowercase hex characters. Required external reference fields are a separately typed object `{systemId, contractVersion, externalId}`: systemId is an application ID, contractVersion/externalId are minimized opaque tokens. They are references, never bearer tokens, credentials, raw engine documents or locators. A future adapter must classify/redact/reject private external tokens before this decoder; shape validation cannot recognize disguised secrets or prove an ID was minted. Existing native content/engine IDs are carried only in external references and are never renamed by this crate.

`FlowContext` fields: `workspaceId`, `systemId`, `environmentId`, `engineId`, `requestId`, `traceId`, `spanId`, `policyRevisionId`. Flow record `context` is required; topology/inventory records have no fake trace. Records are tagged by `kind`, with required `id` and variant fields below. All evidence/actor/resource/policy selectors are application IDs, not free text. ReasonCode is exactly `pending`, `policy_denied`, `scope_mismatch`, `human_required`, `delegation_missing`, `unsupported`, `expired`, `revoked`, `suspended`, `stale`, `conflict`, `unknown_outcome`, `failed`, `cancelled` or `none`.

ActionScope fields: `systemId`, `environmentIds`, `operationClasses`, `resourceIds`, `policyRevisionIds`. No wildcard semantics or arbitrary expressions; tokens cannot contain `*`. O1a preserves decodable incomplete or contradictory plans and initial/successor evaluation predecessor combinations for later diagnostics; quorum semantics, distinct canonical subjects, agent delegation narrowing, human duties, stage cycles and self-expansion cannot be certified by decoding.

MoneyObservation fields: `kind` (`estimate`,`observed`,`final`), `currency` (three uppercase ASCII letters), `amountMicros` integer, `sourceEvidenceId` nullable. This is an observation, not billing/accounting validation. Missing cost/latency is `null`, never normalized to zero. Checks fields: `policyDecision`, `approvalDuties`, `agentDelegation`, `expiryRevocation`, `executionConsumption`, `replayProtection`, `outcomeEvidence`, `reconciliation`, each `yes`,`no` or `unknown`. Reported actor/delegation verification and freshness are preserved source observations, never promoted to verified application identities or eligible approvers. Reported `fully_mediated` and `yes` checks never become qualified coverage; authenticity stays unverified.

## Resource limits

Input and canonical window: at most 2,097,152 bytes each. JSON depth at most 32, total values at most 32,768, individual object at most 64 fields and any raw array at most 1,024 entries. At most 32 producer prefixes and 32 distinct producer IDs across prefixes and tail; combined prefix/tail at most 1,024 events. At most 128 topology nodes and 512 edges. Every other list, including stages, scope sets, approvers, external capability references, evidence lists and pinned revisions, at most 32 entries. Empty lists and explicit nulls preserve unknown/incomplete observations; do not silently drop them. O1b limits bounded lineage/graph traversal to the same event/topology ceilings and must emit gaps/conflicts for impossible relationships.

Integers are 0–9,007,199,254,740,991 to preserve later JavaScript precision; event/cursor sequence must be positive. Timestamp, money, latency, quorum and asOf bounds apply even when optional. Boolean fields accept JSON booleans only. Digests are exactly 64 lowercase hexadecimal characters. Tokens are 1–128 bytes of ASCII letters/digits/underscore/dot/colon/hyphen only; no URLs, slash/backslash, control characters, space, braces, wildcard, free text or arbitrary attributes. This syntactic minimization is not a secret detector or anonymization guarantee.

## Inventory and next reducer

Inventory contains only `schemaVersion` (exact `rangoon.ops.inventory.v1`), `canonicalDigest`, `canonicalBytes`, `producerCount`, `eventCount`, `topologyNodeCount`, `topologyEdgeCount`, `recordCounts` (closed object with all nineteen record kind names and integer counts, including zero), `authority` (exact `none`), `authenticity` (exact `unverified`) and `execution` (exact `unavailable`). `producerCount` counts distinct producer IDs represented by prefixes or tail events; it does not assert authenticated identities. Serialization is read-only: the inventory and decoded window expose no public construction/deserialization path. No success/allowed/verified field, derived approver eligibility, active engine connection or completed execution claim. Duplicate event IDs/producer sequences, conflicting record IDs, broken references, out-of-order/late events and malformed effective-evaluation chains remain explicit O1b relationship inputs, not silently discarded by O1a. Do not advertise an arbitrary decoded archive as a coherent trace.

O1b will implement deterministic snapshot+tail replay and scope/fence/reference validation, retain missing/conflicting records, bind current evaluation/approval observations, preserve unknown effects and generate the shared graph/timeline. Its source contract/review is required before that code. No live feed or action controls are introduced by O1a.
