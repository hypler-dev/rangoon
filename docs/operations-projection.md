## Outcome and boundary

Project one immutable `DecodedWindow` into a shared read-only event timeline and declared graph. Preserve every observation, including duplicates and conflicts, with exact input locations for drill-down. Deterministically flag structural stream, scope, correlation and topology problems. No policy evaluation, identity verification, approver eligibility, effective evaluation selection, authority issuance, execution, I/O, clock, database, collector, transport or native/UI changes.

Every projection fixes `authority: none`, `authenticity: unverified`, `execution: unavailable`, `semanticAssessment: unavailable`, `authoritativeEligibility: unknown`, and `authoritativeEffectiveEvaluationId: null`. No structurally clean window becomes an approval, coherent authorized trace, or qualified coverage. Reported allow/approve/issued/active/completed/verified/full-mediation values remain only reported values. Expiry, delegation narrowing, human duties, reference-to-plan/evaluation/authorization linkage, supersession, conflicting terminal outcomes and reconciliation require O1b-2's separately frozen contract. O3/O4 trusted source admission cannot be supplied by renderer JSON flags.

## API, immutable output and replay

`project_window(&DecodedWindow) -> Result<Projection, ProjectionError>` is the only public projection constructor. `Projection` is privately constructed, not deserializable, with read-only `canonical_bytes()`, `canonical_digest()` and `document()` accessors. The serializable `ProjectionDocument` and its nested DTOs have private fields; no public construction or mutation path. Debug for Projection reports digest and byte count only. Return fixed payload-free error codes `projection_serialization_failed` or `projection_limit`; never parser prose or raw input.

Output schema `rangoon.ops.projection.v1`. Required top-level fields, serialized in this order: `schemaVersion`, `inventory` (O1a's exact inventory), `replay`, `authority`, `authenticity`, `execution`, `semanticAssessment`, `authoritativeEligibility`, `authoritativeEffectiveEvaluationId`, `structuralState`, `snapshotDiagnostics`, `diagnosticCounts`, `timeline`, `nodes`, `edges`. Structural state is `structural_unverified` if no incomplete/conflict flags, `incomplete` if an incomplete flag exists, or `conflict` if any conflict flag exists (conflict wins). It describes only these named structural checks. No diagnostic truncation or silently omitted entities: output exceeding 1,048,576 bytes fails atomically with `projection_limit` and leaves input untouched. Serialization stops at that cap via a bounded writer; do not allocate an unbounded serialized document first.

Replay fields: `canonicalDigest` (input window digest), `snapshotId`, `reducerVersion` (exact existing version), `asOfMs`, `scope` (exact O1a scope), `topologyRevisionId`, `policyRevisionIds`, `coverageRevisionIds`, `prefixes`. Each replay prefix contains `inputPrefixIndex`, `producerId`, `fenceId`, `watermark`; retain every prefix and sort by producer ID, fence ID, inputPrefixIndex. Scope/pin arrays preserve input order. Input digest binds the entire tail as well as prefix metadata. Replay always covers the full exact window; this packet exposes no cutoff, mutable cursor or clock-based query. A late arrival produces a different input identity; it cannot mutate an earlier Projection. No timestamp orders authority or causal precedence.

Timeline has exactly one entry per input event, at most 1,024, sorted lexicographically by `(producerId, fenceId, sequence, eventId, inputOrdinal)`. InputOrdinal is zero-based traversal of prefixes in input order and their events, then tail. Location is the closed tagged union `{kind: prefix, prefixIndex, eventIndex}` or `{kind: tail, eventIndex}`; it selects that exact event in the immutable canonical input. Each entry fields: `inputOrdinal`, `location`, `eventId`, `producerId`, `fenceId`, `sequence`, `previousEventId`, `observedMs`, `receivedMs`, `correlation` (exact nullable O1a correlation), `recordId`, `recordKind`, `eventDigest` (SHA-256 typed event bytes, internal consistency only), `reportedValue` (record state/result/decision/reportedVerification/reportedLevel in that priority, or null), `diagnostics`. Array length and inputOrdinal provide unique UI keys even when event/record IDs repeat. No raw event payload is copied into output; drill-down uses the immutable input location. Costs/latency remain in that exact source event, with null untouched.

Graph contains exactly the declared input nodes (at most 128) and edges (at most 512), retaining duplicates in input order; no inferred nodes or authority relationships are synthesized. Node fields: `inputNodeIndex`, `id`, `kind`, `recordId`, `matchingEventOrdinals` (all matching record-ID observations, sorted numeric), `diagnostics`. Edge fields: `inputEdgeIndex`, `id`, `kind`, `from`, `to`, `diagnostics`. Node kind to expected record kind: actor→actor, workflow→workflow, tool→tool, resource→resource, gateway→gateway_revision, engine→engine, approval_stage→approval_plan. The last is a plan-container selector, not a stage identity: recordId must point to an approval_plan; actual stage relationships remain O1b-2. Graph/table must use the same result in later O2. Declared edges remain unverified, even when endpoints exist.

## Closed structural diagnostics

Diagnostics arrays are sets in the fixed table order below. Counts is a closed object serialized in the same fixed table order, containing every code (including zero), counting affected snapshot/node/edge/event entries, once per code per entry. No unbounded detail objects or lossy diagnostic budget. All comparisons are exact strings/integers, never timestamps. Empty scope sets mean no declared members, not wildcard permission. Exact duplicates retain observations and are idempotent only for structural stream continuity; they do not disappear.

| Code | Severity and exact check |
| --- | --- |
| `duplicate_observation` | Informational: all entries sharing an eventId and byte-identical complete typed event. If any same-ID bytes differ, use event_identity_conflict instead. |
| `event_identity_conflict` | Conflict: all entries with the same eventId when any complete typed event bytes differ. |
| `sequence_conflict` | Conflict: all entries sharing `(producerId,fenceId,sequence)` when complete typed event bytes differ. Exact duplicates do not conflict. |
| `record_identity_conflict` | Conflict: all entries with the same recordId when complete typed record bytes differ, including kind changes. Exact repeated record bytes do not conflict. |
| `sequence_gap` | Incomplete: each stream's first unique sequence is not 1, or any later unique sequence is not predecessor sequence + 1; flag entries at the later/first sequence. Duplicate observations do not introduce gaps. |
| `predecessor_missing` | Incomplete: nonnull previousEventId resolves to no event; or sequence > 1 has null previousEventId. |
| `predecessor_conflict` | Conflict: sequence 1 has nonnull predecessor; or resolved predecessor is ambiguous by differing bytes, another producer/fence, or not exactly sequence minus 1. Exact duplicate predecessor observations count as one byte-identical predecessor. |
| `prefix_fence_mismatch` | Conflict: prefix event producer/fence differs from containing prefix metadata; affected events flagged. |
| `prefix_watermark_mismatch` | Incomplete: empty prefix has nonnull watermark, nonempty prefix has null watermark, or its watermark does not equal that prefix's greatest sequence and matching eventId. If multiple different eventIds tie at greatest sequence, no watermark resolves it. Flag snapshot and every event in affected prefix. |
| `prefix_identity_conflict` | Conflict: more than one prefix declares same producer/fence pair; flag snapshot and every event in those prefixes. Their independent histories are not silently merged as authenticated checkpoints. |
| `scope_mismatch` | Conflict: a nonnull correlation workspace/system/environment/engine is outside declared snapshot scope; record systemId/engineId/environmentId, FlowContext, or ActionScope system/environments/policy IDs are outside snapshot scope/policy pins. Check every direct `policyRevisionId` selector as well as FlowContext policy pins. Empty set does not authorize anything. Operation/resource narrowing remains O1b-2. |
| `correlation_mismatch` | Conflict: FlowContext's eight selectors differ from corresponding correlation selectors (including required request/policy), or evaluation/plan/decision/authorization evaluation selector differs from correlation.evaluationId; evaluation uses its own id. Attempt's attemptId or metric's nonnull attemptId differs from correlation.attemptId. Additionally apply the closed direct-selector matrix below. Null optional evaluation/attempt selectors for other kinds impose no extra fake linkage. |
| `duplicate_node` | Conflict: all declared nodes with repeated node ID, even identical bytes; endpoint identity is ambiguous. |
| `node_record_missing` | Incomplete: no event recordId matches node.recordId. |
| `node_record_kind_mismatch` | Conflict: any matching event has a kind different from the mapping above. |
| `duplicate_edge` | Conflict: all declared edges with repeated edge ID, even identical bytes. |
| `edge_endpoint_missing` | Incomplete: an edge's from or to matches no declared node ID. |
| `edge_endpoint_ambiguous` | Conflict: an edge's from or to matches more than one declared node ID. |


Direct-selector matrix: when correlation is nonnull, any record-level `systemId`, `environmentId`, `engineId` or `policyRevisionId` equals its corresponding envelope selector; a required record policy selector does not equal null. Every direct record `policyRevisionId` must also belong to topology.policyRevisionIds. For records with ActionScope (`gateway_revision`, `delegation`, `authorization`, `suspension`), scope.systemId equals correlation.systemId, scope.environmentIds contains correlation.environmentId, and scope.policyRevisionIds contains the nonnull correlation.policyRevisionId (null or absent membership is a mismatch). Request record.id equals correlation.requestId; evaluation record.id equals correlation.evaluationId. Evidence record.producerId equals event.producerId, independently of correlation. FlowContext still compares all eight selectors. Empty scope sets remain incomplete observations and trigger the specified containment mismatch; there is no wildcard interpretation.

For deliberately context-free inventory with null correlation, direct-envelope comparison is skipped, but snapshot membership still applies. No envelope counterpart exists for actor/resource/gateway/stage/plan/decision/authorization selectors, ActionScope operation/resource sets, externalRefs, record identity of policy_revision or observation supersession; their cross-record relationships are explicitly deferred to O1b-2. Envelope request/evaluation/attempt selectors on other records are not proof those referenced records exist or are current. The presence of a pin likewise does not authenticate a policy.

StructuralState examines snapshot plus all timeline/graph flags; duplicate_observation alone remains structural_unverified. A stream need not have prefix metadata: tail-only streams are allowed and checked from sequence 1. Different fences stay separate streams; same producer changing fence does not itself prove error or continuity. Cross-fence predecessor claims are conflicts. Sequence arithmetic stays within O1a's safe integer ceiling. No recursive traversal: single-step predecessor validation detects incompatible/cyclic stream links without treating them as valid history. General record lineage/stage cycles remain O1b-2.
