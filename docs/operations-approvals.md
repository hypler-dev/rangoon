## Immutable boundary and budgets

`inspect_approvals(&DecodedWindow) -> Result<ApprovalInspection, ApprovalError>` is the sole constructor. It obtains structural, relationship and delegation inspection from the same immutable decoded window. Never accept caller-built projections, trust flags or JSON. No I/O, clock, network, authentication, policy admission, approval routing, authority issuing or execution. Existing four operations schemas and their seventy-seven tests remain unchanged. DTOs serialize with private fields and no public construction, deserialization or mutation. Wrapper canonical_bytes(), canonical_digest(), document() are read-only; Debug exposes only digest and byte count.

Fixed output: authority none, authenticity unverified, execution unavailable, semanticAssessment reported_approval_structure, authoritativeEligibility unknown, authoritativeEffectiveEvaluationId null, authoritativeDutySatisfaction unknown. Numeric vote summaries describe inspectable reported ballots within this supplied window, not eligible approvers, authenticated humans, admitted agent grants, current validity or satisfied duties. No public approved/met/allowed state. Positive report labels never establish authority; explicit rejected/stale/inactive reports remain diagnostics. Denied/unknown evaluations retain their original result; vote counts cannot override them. Historical plans/decisions never migrate to a successor evaluation.

Output cap 1,048,576 bytes uses the existing bounded writer. Independent ceilings checked before copies/emission/walk growth: 1,024 emitted stage rows; 8,192 reference rows (including inherited event references and nested dependency references); 8,192 combined matching ordinals/indices (event/stage references plus decision-chain observations); 8,192 traversal steps (stage dependency inspections and decision lineage walks, one unit per visited ID, including a closing/dangling step). At most 1,024 event rows and chains, inherited from O1a. Dependency walks charge each declared dependency ID when entered, including closing/dangling and repeated diamond entries; the starting stage is not charged without an incoming edge. Decision predecessor walks charge the own ID and each visited/closing/dangling predecessor; a separate root-to-tip output walk also charges each visited ID, while reusing an already retained validated path creates no second conceptual walk. Units describe logical walks, not implementation passes. Stage cycle detection uses path-local active IDs; a completed-node cache cannot suppress a charged diamond re-entry. Iterative exit bookkeeping is not an ID visit. Use iterative bounded walks and one invocation-local immutable record-resolution index; compare each observation with its ID's first typed record bytes once, then use metadata, retaining all ordinals. No persistent/cross-call cache. Failure is atomic, with unchanged input and no dropped rows.

Fixed errors: approval_serialization_failed; approval_structural_limit for structural overflow (including upstream structural errors); approval_relationship_limit for relationship work/wire overflow; approval_delegation_limit for delegation work/wire overflow; approval_limit for this stage's work/wire overflow. Other upstream errors map to serialization_failed. Defensive exact counter boundaries may have private tests; independent fixtures must separately exercise actual stage/reference/match/walk/wire/upstream cases where reachable under earlier caps. Do not claim full-output success at a work ceiling dominated by another cap.

## Decision succession and dependency inspection

Group decisions by exact plan/evaluation/stage and uniquely resolved canonical subject, never actor ID or timestamp. A unique decision node is initial if and only if supersedesDecisionId is null. A nonnull supersedesDecisionId declares a successor with that exact emitted inherited reference; require a uniquely resolved approval_decision predecessor in the same group and seven-field context. At most one distinct successor may name a given predecessor. A self-reference is a cycle, not an initial node. Missing/ambiguous/wrong-kind predecessor maps to the corresponding reference code and decision_incomplete_chain; cross-group/context predecessor maps to decision_binding_mismatch and decision_incomplete_chain. These invalid selectors require unknown_or_conflict and null tip/result. No timestamp, list position, actor alias, or null selector repairs a successor link. Byte-identical repeated IDs are one node with all ordinals retained. More than one initial node or more than one successor gives decision_branch. Missing/ambiguous/wrong-kind predecessor gives reference diagnostics and decision_incomplete_chain. A predecessor must have the same group and seven-field context; otherwise decision_binding_mismatch and decision_incomplete_chain. All observations in a chain must share one producer/fence; otherwise decision_lineage_mismatch. Earliest successor sequence must exceed earliest predecessor sequence; otherwise decision_sequence_mismatch. Cycles give decision_cycle. Require one root, no competing successor, complete connected traversal and no interpretation-blocking diagnostics before selecting a reported tip/result; incomplete/disconnected groups give decision_incomplete_chain and null selectors. Deny/abstain tips remain unchanged. Earlier nodes flag non_tip_decision (information); votes never carry to another plan/evaluation/stage or count aliases twice.

Within each plan occurrence, iteratively inspect every stage's reachable dependency IDs, charging each visited/closing/dangling ID before processing. Missing/ambiguous dependency IDs remain diagnostics; cycles flag stage_dependency_cycle on every stage that reaches the cycle. Union reachable stages' local diagnostics into the dependent stage. Inspect all local stage votes before dependency propagation. A reachable predecessor without interpretable counts, with a reported deny, with fewer observed approvals than its required reported count or with no observed human approval when humanRequired flags dependency_report_shortfall. This describes supplied observations only, never scheduling permission. No topological ordering silently repairs missing stages. Original stage/list order remains unchanged.

Inspection phases are noncircular: immutable event/header/reference/subject/delegation diagnostics; stage declaration diagnostics; decision local binding and lineage; local stage votes; dependency propagation; final plan summary. Decisions inherit their referenced plan header and unique stage declaration diagnostics, never final plan summaries, vote shortfalls or dependency summaries. Aggregate byte-identical header/decision observations before lineage selection. No final summary feeds back into its own input validation. A stage receives diagnostics from every decision observation claiming its plan/stage, including malformed/ambiguous/unresolved actors. Only a group's valid reported tip contributes one vote; interpretation-blocking observations make the stage summary null. Plans aggregate stage diagnostics. Chain diagnostics aggregate all their decision observations. Informational alias/old-node diagnostics do not hide conflicts.
