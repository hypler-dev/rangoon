# Rangoon

The control plane for governed AI.

Rangoon brings agent capabilities, skills, workflows, connectors, policies, testing, and deployment into a common control plane. The project is in active development.

## Application source

This repository is reserved for the Rangoon application. Application source, development instructions, licensing, and release information will be added here as the project is prepared for publication.

There is no application download or installation command available yet.

The public product website is [rangoon.ai](https://rangoon.ai). Its marketing-site implementation is maintained separately and is not the application source.
